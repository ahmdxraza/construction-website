# 🏗️ Construction Website

A responsive construction website inspired by the Colorlib Construction template, built using HTML, CSS, and Bootstrap.

## 🚀 About the Project

This project recreates a construction company website layout with a modern design, responsive sections, project gallery, statistics, client feedback, and contact form.

## ✨ Features

- Responsive navigation bar
- Construction hero section
- Services section
- Features and benefits
- Project gallery
- Statistics section
- Client feedback section
- Latest blog posts
- Contact form
- Footer with company information
- CSS hover effects and animations
